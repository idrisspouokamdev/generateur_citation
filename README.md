# Générateur de citations

Un générateur de citations aléatoires réalisé en HTML, CSS et JavaScript.

## Fonctionnalités
- Affichage d'une citation aléatoire
- Auteur associé à chaque citation
- Design moderne et responsive
- Interface simple et intuitive

## Technologies
- HTML5
- CSS3
- JavaScript (tableau, fonctions, événements)

## Installation
Ouvrir le fichier `index.html` dans un navigateur.
